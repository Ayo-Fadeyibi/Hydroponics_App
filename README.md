# AI-Optimised Hydroponic Analytics Platform (Project 6)

> DECO3801 — University of Queensland (Team Passionfruit)

An AI-Optimised hydroponic analytics platform that simulates crop growth based on environmental conditions, forecasts yield outcomes using machine learning trained on historical datasets, and compares AI-optimised configurations against user's current setup/simulation. Enables LLM-generated recommendations based on current simulation or user crop growth data.

## Application Feature Breakdown

### 1) SimLab — Environment Simulator & AI Optimiser

- Adjust environmental variables (e.g., pH, temperature, humidity, nutrient levels, light)
  via an interactive slider-based dashboard
- Real-time dynamic plant growth graphic reflects current simulation settings
- Compares the user's current simulated configuration against an AI-optimised setup,
  displaying side-by-side growth curves and projected yield outcomes for both scenarios
- LLM-generated recommendations explain how to close the gap between the user's
  setup and the optimised configuration

### 2) YieldIQ — Predictive Yield Forecasting

- Input your own crop growth data, which is validated before being passed to the predictive model
- Specify a forecast window (number of days) to generate a projected growth curve
  estimating future yield performance
- LLM-generated recommendations provide actionable insights derived from your specific
  dataset and predicted outcomes

## Datasets Used To Train The ML Models

### Tomato Dataset

Buck, J.S., Kubota, C. and Jensen, M. (2008) ‘Effect of mid-day reduction of high electrical conductivity treatment on the yield and quality of Greenhouse Cherry Tomato’, HortTechnology, 18(3), pp. 460–466. doi:10.21273/horttech.18.3.460.

Kubota, C., Eguchi, T. and Kroggel, M. (2017) ‘UV-B radiation dose requirement for suppressing intumescence injury on Tomato Plants’, Scientia Horticulturae, 226, pp. 366–371. doi:10.1016/j.scienta.2017.09.006.

Autonomous Greenhouse Challenge, Second edition (2019) (dataset). Available at: https://data.4tu.nl/articles/dataset/Autonomous_Greenhouse_Challenge_Second_Edition_2019_/12764777/2.

### Cucumber Dataset

Tran, K., CEAOD, Controlled Environment Agriculture Open Data. Available at: https://ceaod.github.io/

Hemming, S., de Zwart, F., Elings, A., Righini, I., & Petropoulou, A. Remote Control of Greenhouse Vegetable Production with Artificial Intelligence—Greenhouse Climate, Irrigation, and Crop Production. Sensors, 19(8). 2019.

### Lettuce Dataset

Métwalli, A. et al. (2025) ‘Enhancing hydroponic farming with machine learning: Growth prediction and anomaly detection’, Engineering Applications of Artificial Intelligence, 157, p. 111214. doi:10.1016/j.engappai.2025.111214.

## Getting Started

You need **two terminals open simultaneously** — one for the frontend, one for the backend.
Set up information for each specific terminal can also be found in the specific README.md files in the backend/ and frontend/ directories.

---

### Terminal 1 — Start the Backend (FastAPI)

```sh
cd backend
```

**1 - Create and activate virtual environment:**

macOS / Linux — create and activate virtual environment:

```sh
python -m venv .venv
source .venv/bin/activate
```

Windows — create and activate virtual environment:

```sh
python -m venv .venv
.venv\Scripts\Activate
```

**2 - Install dependencies and start the server:**

```sh
pip install -r requirements.txt
fastapi dev
```

Backend is now running at:

```
http://localhost:8000
http://localhost:8000/docs   ← Swagger UI (interactive API docs)
```

---

### Terminal 2 — Start the Frontend (React + Vite)

**1. Install Node.js**

Make sure you have Node.js installed (version 18+ recommended).

Check your version:

```sh
cd frontend
node -v
npm -v
```

**2. Install Dependencies and Run**

```sh
npm install
npm run dev
```

Frontend is now running at:

```
http://localhost:5173
```

> The Vite proxy automatically forwards `/api/*` requests from the frontend to the backend at `localhost:8000`. No extra configuration needed.
