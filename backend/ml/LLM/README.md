## central_get_guidance Usage

First, import the get_llm_guidance function. It is in central_get_guidance.py

```
from central_get_guidance import get_llm_guidance
```

The function for AI based recommendations is get_llm_guidance(current_metrics, locked_variables, crop_type).

- current_metrics expects a dictionary with current readings,
- locked_variables expects a dictionary with any locked variables at their locked values
- crop_type is a string of either lettuce, tomato, or cucumber.

```
current_metrics = {
    'Avg_pH': 6.26, 'Avg_EC': 2.32, 'Avg_CO2': 450,
    'Avg_RH': 60.0, 'Avg_Air_Temp': 21, 'Avg_Water_Temp': 23.8, 'Avg_TDS': 1.6
}
locked_variables = {'Avg_Air_Temp': 21}
crop_type = "lettuce"
advice = get_llm_guidance(current_metrics, locked_variables, crop_type)
```

Any locked variables are expected to the the same as their current_metric value.

## Expected Output

The function returns a HydroponicAdvice object (Pydantic model) with the following structure:

### Fields:

| Field          | Type      | Description                                                 |
| -------------- | --------- | ----------------------------------------------------------- |
| status         | str       | Overall health (e.g., "Optimal", "Suboptimal", "Critical"). |
| advice_summary | str       | A brief, friendly summary of the current state.             |
| action_steps   | list[str] | physical actions to take (e.g., "Add pH Down...").          |
| priority_score | int       | Urgency rating from 1 to 10.                                |

### Example response:

The response is outputted as JSON:

```
{
  "status": "Suboptimal",
  "advice_summary": "Your nutrient concentration is a bit high for your current settings.",
  "action_steps": [
    "Add fresh water to the reservoir to reach your target EC of 2.26."
  ],
  "priority_score": 4
}
```

To parse the response correctly, the fields can be extracted from the HydroponicAdvice object in this way:

```
advice = get_llm_guidance(current_metrics, locked_variables)
status = advice.status

```

## feature_2_get_guidance usage

First, import the function:

```
from feature_2_get_guidance import get_user_data_guidance
```

The function to get LLM answers for user inputted data is get_user_data_guidance(feature_importance, plant)

inputs:

feature_importance: expects a dictionary of feature importance, this can be generated by the get_feature_importance(df) function in ml/UserDataModel.

plant: name of the plant (fetch from excel file name)

```
df = pd.read_csv("ml/UserDataModels/exampleCSV.csv")
feature_importance = get_feature_importance(df)
plant = "tomato"

ai_output = get_user_data_guidance(feature_importance, plant)
```

## Output:

UserDataAdvice object with a field "advice"

```
advice = ai_output.advice
print(advice)
```
